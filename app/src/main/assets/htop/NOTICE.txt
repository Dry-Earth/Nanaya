Bundled htop
============

htop 3.5.3
License: GPL-3.0-or-later
Source: https://github.com/htop-dev/htop

ncurses 6.5
License: MIT-style (ncurses)
Source: https://invisible-island.net/ncurses/

Both are built statically with musl-gcc for aarch64 so the binary can run on
Android's Linux kernel. See tools/build-htop.sh in the Nanaya repository for
the exact build steps.

htop is executed as root from /data/local/tmp so it can read every /proc
entry. No source code of Nanaya itself is linked to it.
